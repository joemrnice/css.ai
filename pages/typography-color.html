Loading web fonts

fonts.css
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-weight: 400 700;   /* variable font weight range */
  font-display: swap;    /* show fallback text immediately, swap when ready */
}

body {
  font-family: "Inter", system-ui, sans-serif; /* always give a fallback stack */
}
font-display valueBehavior
swapFallback shows instantly, swaps once the font loads — best for readability
blockBriefly invisible text, then swaps — avoids a flash of unstyled text but can flash blank
optionalBrowser decides whether to wait at all, based on connection speed

Core type properties

PropertyPurpose
line-heightUnitless values (e.g. 1.5) scale with font-size and inherit cleanly — prefer these over px/em line-heights
letter-spacingTracking between characters — small negative values often improve large display headings
text-wrap: balanceEvens out line lengths in headings so they don't end with one orphan word
font-variation-settingsFine control over variable font axes beyond weight, e.g. width or optical size

Ways to write a color

color-syntax.css
color: #7aa2f7;                     /* hex */
color: rgb(122 162 247);            /* space-separated modern syntax */
color: rgb(122 162 247 / 60%);      /* with alpha */
color: hsl(221 88% 72%);            /* hue, saturation, lightness — easy to tweak by feel */
color: oklch(0.72 0.12 260);        /* perceptually uniform — equal steps *look* equal */
color: CornflowerBlue;           /* one of 147 named colors */
Why oklch is gaining ground

In HSL, lowering "lightness" on different hues doesn't darken them by the same perceived amount — blues get muddy faster than yellows. oklch() is built so equal changes in its lightness channel look equally different to the human eye, which makes generating a whole color scale programmatically far more reliable.

Color functions

color-mix.css
/* blend two colors without a preprocessor */
.btn:hover {
  background: color-mix(in oklch, var(--brand) 85%, white);
}

/* tint a color using the current value plus transparency */
.badge {
  background: rgb(from var(--brand) r g b / 12%);
}

Accessible contrast

WCAG 2.1 AA requires a contrast ratio of at least 4.5:1 for normal text and 3:1 for large text (18pt+/24px+, or 14pt+/18.66px+ bold) against its background. Always check text-on-color combinations, not just your default palette in isolation — a brand blue that passes on white may fail on your dark surface color.

Don't rely on color alone

Error states, required-field markers, and links inside body text should have a second signal besides color — an icon, underline, or label — for users with color vision deficiencies.

Interview angle

Q: What's the difference between HSL and OKLCH, and why would you switch? Both are cylindrical color models with a lightness channel, but OKLCH is perceptually uniform, so it's better for generating consistent color scales or interpolating between colors without muddy midpoints.

CSS Grid

A two-dimensional layout system — rows and columns at the same time. Where flexbox distributes items along one line, grid places them on an actual coordinate system.

Defining tracks

grid-basics.css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;   /* sidebar + fluid content */
  grid-template-rows: auto 1fr auto;  /* header, content, footer */
  gap: 24px;
}

repeat() avoids writing the same track size many times: grid-template-columns: repeat(4, 1fr); is four equal columns.

The fr unit

fr represents a fraction of the leftover space after fixed-size tracks and gaps are subtracted — not a fraction of the whole container. grid-template-columns: 200px 1fr 2fr; gives the second column one share of what's left and the third column two shares.

min-content trap

An fr track still won't shrink below its content's min-content size by default — a long unbreakable word can blow out a grid. Fix it with minmax(0, 1fr) instead of plain 1fr.

Named areas

grid-template-areas lets you literally draw the layout in the CSS:

areas.css
.page {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar main"
    "sidebar footer";
}
.sidebar { grid-area: sidebar; }
header   { grid-area: header; }
main     { grid-area: main; }
footer   { grid-area: footer; }

This is especially powerful combined with a media query — redefine grid-template-areas at a breakpoint and every child automatically moves, with zero changes to markup or the children's own CSS.

Placing items by line number

placement.css
.hero-image {
  grid-column: 1 / 3;   /* from line 1 to line 3 — spans 2 columns */
  grid-row: 1 / span 2; /* start at line 1, span 2 rows */
}

Grid lines are numbered starting at 1, and -1 always refers to the last line — handy for "span to the end" without knowing the exact column count.

auto-fit vs auto-fill

The classic responsive-cards-with-no-media-query pattern:

responsive-grid.css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}

Both create as many 220px+ columns as fit. The difference only shows when there are fewer items than columns that would fit: auto-fill keeps the empty tracks (items stay their minmax width, don't stretch), while auto-fit collapses empty tracks to 0 and lets existing items stretch to fill the row.

Subgrid

Normally a grid item's own children can't align to the parent grid's tracks — grid-template-columns: subgrid fixes that, letting a nested grid inherit its parent's track sizing so, for example, card titles and prices align across a row of independently-sized cards.

subgrid.css
.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid; /* inherit the parent grid's row tracks */
}
Interview angle

Q: Flexbox or Grid — which do you reach for? Grid when you're laying out two dimensions at once (rows and columns) or need explicit placement; flexbox when you're distributing items along a single line and want content to dictate sizing. Many real layouts use both — grid for the page skeleton, flexbox inside individual components. More in the interview guide.

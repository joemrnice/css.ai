Mobile-first

Write base styles for the smallest screen, then use min-width media queries to layer on complexity as space increases. This keeps mobile fast (it isn't fighting overrides) and tends to produce simpler CSS than writing for desktop and un-doing it for mobile with max-width queries.

mobile-first.css
.cards { display: grid; gap: 16px; } /* one column by default */

@media (min-width: 640px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}

Media queries

FeatureExample
Width@media (min-width: 768px)
Orientation@media (orientation: landscape)
Hover capability@media (hover: hover) — true touch devices report none
Pointer precision@media (pointer: coarse) — touch vs mouse
Combine conditions@media (min-width: 768px) and (max-width: 1023px)
Range syntax

Modern browsers support comparison-style ranges: @media (768px <= width < 1024px) — more readable than min-width/max-width pairs.

Container queries

Media queries respond to the viewport. Container queries respond to a component's own container's size — meaning the same card component can react to being placed in a narrow sidebar or a wide main column, independent of screen size.

container-queries.css
.card-wrapper {
  container-type: inline-size; /* opt this element in as a query container */
  container-name: card;
}

@container card (min-width: 400px) {
  .card { grid-template-columns: 120px 1fr; } /* image beside text once there's room */
}

Fluid type with clamp()

clamp(min, preferred, max) replaces a stack of media queries just for font-size with one line that scales smoothly:

fluid-type.css
h1 {
  /* never smaller than 2rem, never larger than 3.5rem,
     otherwise scales with viewport width */
  font-size: clamp(2rem, 1.2rem + 3vw, 3.5rem);
}

User-preference queries

preferences.css
@media (prefers-color-scheme: dark) { /* system dark mode */ }
@media (prefers-reduced-motion: reduce) { /* respect motion sensitivity */
  * { animation-duration: 0.01ms !important; }
}
@media (prefers-contrast: more) { /* accessibility setting */ }

This site respects prefers-reduced-motion — check the bottom of style.css for the pattern.

Interview angle

Q: Media query vs container query — when does each apply? Media queries describe the viewport/device; container queries describe a specific element's own box. Reach for container queries when a reusable component (a card, a widget) needs to adapt based on where it's dropped, not on screen size. More in the interview guide.

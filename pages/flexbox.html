The two axes

Flexbox lays children out along a main axis (set by flex-direction) and can align them along the perpendicular cross axis. This mental model explains every flex property — they all either distribute space on the main axis or align items on the cross axis.

flex-basics.css
.row {
  display: flex;
  flex-direction: row;    /* main axis = horizontal (default) */
}
.stack {
  display: flex;
  flex-direction: column; /* main axis = vertical */
}

Center anything, one line

display: flex; align-items: center; justify-content: center; — the answer to "how do I center a div" that used to require negative margins and guesswork.

Item properties

order and accessibility

order only changes visual/tab order in some browsers inconsistently — screen readers still follow DOM order. Don't use it to fix content that's in the wrong place in the markup.

grow, shrink, and basis

flex-shorthand.css
.item {
  flex-grow: 0;    /* share of *extra* space this item takes, relative to siblings */
  flex-shrink: 1;  /* how much this item shrinks when space is too tight */
  flex-basis: auto; /* starting size before grow/shrink is applied */
}

/* the three most common shorthands */
.fixed    { flex: none; }         /* 0 0 auto — never grow or shrink */
.flexible { flex: 1; }            /* 1 1 0% — fill and share space equally */
.min-220  { flex: 1 1 220px; }    /* grow/shrink starting from 220px */

The most-misunderstood part: flex: 1 sets flex-basis: 0%, not auto — every item starts from zero and grows purely by ratio, ignoring its content size as a starting point. That's different from flex: 1 1 auto, which starts from the content's natural size first.

Common recipes

navbar.css
/* logo left, links right, vertically centered */
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

/* equal-width card row that wraps on small screens */
.card-row {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}
.card-row > * {
  flex: 1 1 240px; /* grow, shrink, never below 240px */
}

/* sticky footer pattern */
body { display: flex; flex-direction: column; min-height: 100vh; }
main { flex: 1; }
Interview angle

Q: What's the difference between flex: 1 and flex: auto? Both grow and shrink, but flex: 1 ignores the content's natural size (basis 0%) while flex: auto uses it as the starting point (basis auto) — so items with more content start larger. Full walkthrough in the interview guide.

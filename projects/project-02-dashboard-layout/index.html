How it's built

  • The skeleton: .app is a grid with named areas — grid-template-areas literally spells out the layout, so it reads like a diagram rather than a set of coordinates.
  • Sticky header: .app-header uses position: sticky; top: 0; combined with its scroll container (.app-main for a page-level version of this pattern, or the grid's own overflow here) — it needs a defined scrolling ancestor to stick within.
  • The one breakpoint: at 640px, grid-template-columns collapses to one column and grid-template-areas is redefined to stack sidebar → header → main. Every child just has grid-area: sidebar etc. — no per-child media queries needed.
  • Stat cards: a simple grid-template-columns: repeat(3, 1fr) that becomes 1fr on mobile.

How it's built

  • Row layout: display: flex; flex-wrap: wrap; on .pricing — cards use flex: 1 1 260px so they grow evenly and wrap to fewer columns before overflowing.
  • The "pop out" effect: .featured gets transform: scale(1.05) and a heavier box-shadow, plus z-index: 1 so its shadow and scaled edges render above its neighbors instead of behind them.
  • The badge: positioned with position: absolute; top: -12px; left: 50%; transform: translateX(-50%); — the classic centered-overflow-badge pattern, anchored to .featured's own position: relative (inherited here from .plan being a flex item, which is itself not a positioning context — note .plan.featured gets position: relative explicitly for this reason).
  • Disabled features: a .off class swaps the checkmark for a dash via ::before and dims the text — no separate icon asset needed.
  • Responsive: at 720px the row becomes a column and transform: none removes the scale-pop, since it would otherwise visually collide with cards above/below it once stacked.
Try extending it

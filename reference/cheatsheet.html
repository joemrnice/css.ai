Common gotchas

  • Margin collapsing only applies to vertical margins between in-flow block siblings.
  • flex: 1 sets basis to 0% (ignores content size) — flex: auto keeps the content size as the starting point.
  • z-index only compares within the same stacking context.
  • position: absolute needs a positioned ancestor or it targets the whole page.
  • ::before/::after need content to render, even content: "";.
  • An fr track still respects min-content — use minmax(0, 1fr) to allow full shrinking.

Animation performance

Cheap (compositor only): transform, opacity

Expensive (triggers layout): width, height, top, left, margin

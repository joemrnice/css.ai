CSS-only carousel

A swipeable, snap-to-slide carousel with dot navigation — the whole thing is scroll-snap plus native scrolling. Swipe or drag the track below; no JavaScript is loaded on this page.

How it's built

  • The track: .carousel-track is just a flex row with overflow-x: auto — the browser gives you native scrolling, touch/trackpad support, and momentum for free.
  • Snapping: scroll-snap-type: x mandatory on the track tells the browser the scroll position must always rest on a snap point. Each .slide declares scroll-snap-align: start as that point.
  • Full-width slides: flex: 0 0 100% makes each slide exactly the track's width and prevents it from shrinking, so exactly one slide is visible at a time.
  • Dot navigation without JS: each dot is a plain anchor link (href="#slide-2") to the matching slide's id. Clicking it triggers the browser's native in-page scroll-to-anchor behavior — combined with scroll-behavior: smooth on the track, that scroll animates instead of jumping instantly.
  • Hiding the scrollbar: scrollbar-width: none (Firefox) and the ::-webkit-scrollbar override (Chrome/Safari) hide the native bar so the dots read as the only navigation UI, while the underlying scroll container still works with touch, trackpad, and keyboard.
Known limitation

Because there's no JavaScript, the dots can't visually highlight which slide is "active" purely from anchor navigation — :target only matches after a same-page anchor click, not after a manual swipe. A small JS enhancement (an IntersectionObserver watching each slide) is the natural next step if that matters for your use case.
